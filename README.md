# Anita Jepngetich Personal Portfolio
A personal portfolio website for Anita Jepngetich. It is a single scrolling page with three sections.

**Features**:
Centered header with my name and a link to my GitHub profile
Navigation links that scroll smoothly to each section
About Me section with a short bio, photo, programming languages, engineering skills and hobbies
Projects section with project cards, each showing an image, name and description
Contact section with an email link
Responsive layout that works on phones and desktops
Consistent dark and pink color scheme
Projects Showcased
Store Inventory Management System: a simple system to manage a store's product inventory.
Client Portfolio UI Redesign: improved the user interface of a client's portfolio website.
Real-Time Electrical Fire Protection Scheme: a real-time scheme built to help reduce the risk of electrical fires.

**Built With**:
HTML5
CSS3 (Flexbox for layout)
Poppins font from Google Fonts
